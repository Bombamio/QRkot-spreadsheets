# Cat Charity Fund

## Описание проекта

Cat Charity Fund — это сервис для поддержки благотворительных проектов, направленных на помощь кошкам. Пользователи могут создавать благотворительные проекты и делать пожертвования. Все поступающие средства автоматически распределяются между открытыми проектами по принципу очередности.

Проект разработан на FastAPI и предоставляет REST API для работы с благотворительными проектами и пожертвованиями.

## Основные возможности

* Создание благотворительных проектов.
* Редактирование открытых проектов.
* Закрытие проектов после сбора необходимой суммы.
* Создание пожертвований.
* Автоматическое распределение пожертвований между открытыми проектами.
* Получение списка проектов и пожертвований.
* Валидация данных и контроль бизнес-логики.
* Аутентификация и авторизация пользователей.

## Установка проекта

### Клонирование репозитория

git clone <repository_url>

cd <project_directory>

### Создание виртуального окружения

python -m venv venv

Для Linux/macOS:

source venv/bin/activate

Для Windows:

venv\Scripts\activate

### Установка зависимостей

pip install -r requirements.txt

## Настройка переменных окружения

Создайте файл .env в корневой директории проекта.

Пример содержимого:

APP_TITLE=Cat Charity Fund
APP_DESCRIPTION=Service for charity projects
DATABASE_URL=sqlite+aiosqlite:///./fastapi.db
SECRET=your_secret_key

## Применение миграций

alembic upgrade head

## Основные сущности

### CharityProject

Благотворительный проект содержит:

* название проекта;
* описание;
* требуемую сумму;
* сумму собранных средств;
* дату создания;
* дату закрытия;
* статус проекта.

### Donation

Пожертвование содержит:

* сумму пожертвования;
* дату создания;
* информацию о пользователе;
* статус распределения средств.

## Правила работы

* Нельзя удалять проект, в который уже были инвестированы средства.
* Нельзя изменять закрытый проект.
* Новая требуемая сумма не может быть меньше уже инвестированной.
* Проект автоматически закрывается после сбора необходимой суммы.
* Пожертвования автоматически распределяются между открытыми проектами.
